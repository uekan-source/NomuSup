# Nomu-Sup（ノムサプ）｜ 薬剤師監修・二日酔い対策ソムリエ

## サービス概要
「飲み会前」「飲酒中」「翌朝」の3つのタイミングに合わせて、**薬学的根拠に基づいた「今、コンビニや薬局で買うべき対策セット」を提案**するWebアプリです。
ユーザーの状態を選択するだけで、薬剤師の思考プロセスを再現したアルゴリズムが、最適なサプリメント・市販薬・食品の組み合わせをレコメンドします。

※本アプリは「診断・治療」を目的としたものではなく、あくまで「セルフメディケーションを支援する情報提供」という位置付けです。

---

## このサービスへの思い・作りたい理由
薬剤師として働く中で、二日酔いに苦しむ人々が「脱水状態なのにカフェインを摂る」といった、医学的に逆効果な対処法を選んでしまっている場面を多く見てきました。
「科学的に正しいタイミングで、正しい成分を摂取すれば、翌日のパフォーマンスは守れる」という確信があります。
しかし、飲み会の最中や二日酔いの時に専門情報を調べるのは困難です。そこで、**「酔っ払っていても、辛い朝でも、数タップで専門家の正解に辿り着けるツール」**を提供し、人々の健康と翌日の生産性を守りたいと考え開発しました。

## ユーザー層について
* **ターゲット：** 20〜30代の働く世代・学生
* **選定理由：** * 付き合いでの飲酒機会が多く、翌日の仕事や学業への影響を最小限にしたいという切実なニーズがある。
    * 健康管理のために「コンビニで数百円の対策」を講じるハードルが低く、スマホでの情報検索が習慣化しているため。

## サービスの利用イメージ
1.  **飲み会直前（予防）：** 「これから飲む」を選択。空腹状態や飲む量に応じ、胃粘膜保護（乳製品）や肝機能補助（ヘパリーゼ等）の最適なセットが提案されます。
2.  **飲み会後（代謝促進）：** 「飲みすぎた」を選択。アルコール分解を助ける糖分（ラムネ）や水分、代謝を早める特定食品を提案し、翌朝へのダメージを軽減します。
3.  **翌朝（対症療法）：** 「頭痛」「吐き気」などの症状を選択。薬剤師のロジックに基づき、胃への負担を考慮した鎮痛剤や、漢方薬（五苓散等）の具体的な商品名を提案します。

## ユーザーの獲得について
* **職場・知人へのテスト導入:** 職場の同僚や友人にプロトタイプを共有し、実際の飲み会前後に使用してもらうことで、実用性に関するフィードバックを直接収集します。

## サービスの差別化ポイント・推しポイント
* **圧倒的な「具体性」：** 単なる記録や「水を飲みましょう」という注意喚起ではなく、「何を買えばいいか」という具体的な解決策を提示します。
* **薬剤師ならではの「消去法ロジック」：** 「胃が痛いならこの鎮痛剤は避ける」といった、専門家視点の安全性を考慮した分岐アルゴリズムを搭載。
* **UI/UXのこだわり：** 飲酒時や二日酔い時の「認知機能の低下」を考慮し、文字を読まなくてもイラストでタップできるフラットなデザインを追求しました。

## 機能候補

### 1. 薬剤師ロジック搭載・3ステップ診断
* 「タイミング（前・中・翌朝）」「症状」「体質」を選択するだけで、最適な対策を診断。
* 二日酔いで文字を読むのが辛い状態でも直感的に操作できるよう、**全選択肢をオリジナルのイラストで視覚化**しています。

### 2. あなたへの処方箋（対策レコメンド）
* **具体的な商品名の提示：** 「ヘパリーゼW」「五苓散」など、コンビニや薬局ですぐ買える具体的な商品名を提案。
* **薬剤師のワンポイントアドバイス：** 「なぜこの成分が必要か」「飲むときの注意点（胃腸への負担など）」をわかりやすく解説。
* **購買導線の確保：** 提案された商品の「Amazonで探す」ボタンや、現在地から「近くのコンビニ/薬局を探す（Google Maps API連携）」ボタンを実装。

### 3. アルコール分解シミュレーター
* 体重、性別、体質（お酒への強さ）を入力し、飲んだお酒をタップしてカートに追加するだけで、**「体からアルコールが完全に抜けるまでの目安時間」**を自動計算。
* 飲酒運転の防止や、翌日の予定に向けたセルフコントロールを支援します。

### 4. マイ薬箱（診断履歴の保存機能）
* 過去の診断結果とお薬の提案履歴をマイページに保存。
* ユーザーごとの体重や体質データも保存され、次回以降のシミュレーション入力が省力化されます。

### 5. Google / メールアドレス 認証機能
* 手軽にログインできるよう、OAuthを利用したGoogleログインと、通常のメールアドレスログインを実装。

## 競合調査と差別化ポイント
調査したところ、以下の類似サービスがありましたが、本サービスは「解決策の具体性」で差別化を図ります。
- **飲酒記録アプリ:** 「記録」が主目的であり、その場での「対策」を提示する機能は限定的。
- **医療相談サイト:** 専門家の回答が得られるが、飲み会中や翌朝の「今すぐ」というスピード感に欠ける。
- **WEB記事:** 網羅的な情報は多いが、「胃が痛い時はこの薬は避ける」といった個人の状況に合わせた「成分の消去法ロジック」は提供されていない。
→ **結論:** 薬剤師の判断基準をアルゴリズム化することで、「今、自分が何をすべきか」を数秒で導き出す点に独自性があります。
